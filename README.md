# WhisperAIScript (v6) — Простая расшифровка видео и аудио в текст

Готовый набор программ для перевода любых видеозаписей, лекций, созвонов и голосовых сообщений в чистый текст на компьютере с Windows 10 или Windows 11.

Вся обработка идёт прямо на вашей видеокарте (или процессоре) — бесплатно, без ограничений по длительности и без отправки личных записей на сторонние серверы.

---

## Что умеет эта программа

* **Переводит видео и аудио в текст:** поддерживает форматы `.mp4`, `.mkv`, `.avi`, `.mov`, `.mp3`, `.wav`, `.m4a`, `.webm`, `.flac`, `.ogg`.
* **Обрабатывает сразу много файлов:** можно выбрать как один ролик, так и целый курс лекций — программа по очереди расшифрует всё и соберёт в единый документ.
* **Создаёт сразу два удобных файла рядом с вашим видео:**
  1. `ИмяФайла_text.txt` (или `Общая_расшифровка_текст.txt`) — сплошной чистый текст, готовый для чтения, конспектов или отправки в нейросеть.
  2. `ИмяФайла_timestamps.txt` (или `Общая_расшифровка_таймкоды.txt`) — текст, разбитый по времени (`[00:01:15 -> 00:01:22] ...`), чтобы легко найти нужный момент в видео.
* **Наглядно скачивает и докачивает языковую модель (новое в v6):** при первом запуске модель (~1.62 ГБ) скачивается прямо в папку `./models/large-v3-turbo/` с видимой шкалой прогресса (мегабайты, проценты и скорость). Если интернет прервётся, при следующем запуске скачивание продолжится с того же места (`.part`), а не с нуля.
* **Не зависает при скачивании на Windows и обходит блокировки:** отключён зависающий фоновый модуль `hf_xet`, а при недоступности основного сервера `huggingface.co` программа сама переключается на резервное зеркало `hf-mirror.com` и запасные репозитории. После первой загрузки программа работает полностью без интернета.
* **Работает даже на видеокартах с 4 ГБ памяти** (например, NVIDIA GeForce GTX 1650 Ti): если памяти видеокарты вдруг не хватит на тяжёлом файле, программа не вылетит и не испортит уже записанный текст, а сама переключится на более лёгкий режим.

## Быстрый старт (в 2 шага)

### Шаг 1. Установка (делается один раз)
Запустите двойным кликом файл **`Install Whisper.bat`**.

* Если у вас ещё не установлен Python, программа сама подскажет, что делать, и откроет страницу загрузки.
* Если Python уже есть (поддерживаются как стабильный **Python 3.14**, так и новый **Python 3.15**), установщик сам скачает все нужные библиотеки и создаст рабочий файл `translate_v4_argon.py`.
* Дождитесь надписи `[✓] Скрипт translate_v4_argon.py успешно создан!` и нажмите любую клавишу.

### Шаг 2. Расшифровка видео или аудио
У вас есть два удобных способа запуска:

1. **Через окно выбора файлов:**
   Запустите двойным кликом **`Run Whisper.bat`**. Появится стандартное окно Windows — выберите в нём один или несколько видео/аудиофайлов (несколько файлов можно выделить с зажатой клавишей `Ctrl` или `Shift`) и нажмите «Открыть».
2. **Перетаскиванием (Drag-and-Drop):**
   Просто перетащите мышкой нужный видеофайл (или сразу несколько файлов) прямо на иконку **`Run Whisper.bat`**. Расшифровка начнётся мгновенно без лишних окон.

> **Примечание:** в версии **v6** актуальный код `translate_v4_argon.py` также встроен прямо внутрь `Run Whisper.bat` и автоматически обновляется при каждом запуске. При самом первом запуске программа один раз скачает языковую модель (~1.62 ГБ) в папку `models/large-v3-turbo/`, а во все следующие разы будет запускаться за 1–2 секунды полностью оффлайн.

## Описание файлов запуска

| Файл | Назначение |
| :--- | :--- |
| **`Install Whisper.bat`** | **Установщик зависимостей.** Запускается один раз для установки библиотек под найденные в системе Python 3.14 / 3.15 (также можно передать версию аргументом: `Install Whisper.bat 3.14` или `Install Whisper.bat 3.15`). |
| **`Run Whisper.bat`** | **Ежедневный запуск расшифровки.** Автоматически обновляет `translate_v4_argon.py`, выбирает рабочий интерпретатор Python и запускает транскрибацию (для принудительного выбора версии Python поддерживает запуск вида `Run Whisper.bat 3.14` или `Run Whisper.bat 3.15`). |
| **`translate_v4_argon.py`** | **Ядро транскрибатора.** Генерируется и обновляется автоматически из `.bat`-файлов в кодировке UTF-8 без BOM. |

## Как работать полностью без интернета (оффлайн-режим)

Начиная с версии **v6**, программа при первом запуске автоматически сохраняет модель в локальную папку `models/large-v3-turbo/` рядом со скриптом (а также проверяет стандартный системный кэш `~/.cache/huggingface/hub/`).

Если вы хотите заранее перенести программу на компьютер, где вообще нет интернета:

1. Скопируйте папку с программой вместе с уже скачанной папкой `models/large-v3-turbo/` (или создайте путь `models/large-v3-turbo/` вручную).
2. Убедитесь, что внутри лежат файлы модели (`model.bin` размером ~1.6 ГБ, `config.json`, `tokenizer.json`, `vocabulary.json` / `preprocessor_config.json`) из репозитория [mobiuslabsgmbh/faster-whisper-large-v3-turbo](https://huggingface.co/rtlingo/mobiuslabsgmbh-faster-whisper-large-v3-turbo/tree/main) или [deepdml/faster-whisper-large-v3-turbo-ct2](https://huggingface.co/deepdml/faster-whisper-large-v3-turbo-ct2).
3. Программа проверит целостность `model.bin` и запустит модель напрямую с диска (`local_files_only=True`) без обращения к сети.

## Частые вопросы

* **Где искать готовый текст после завершения?**
  Прямо в той же папке, где лежит ваше исходное видео. Если вы выбрали один файл `Лекция_1.mp4`, рядом появятся `Лекция_1_text.txt` и `Лекция_1_timestamps.txt`. Если выбрали сразу несколько файлов — в их папке появятся `Общая_расшифровка_текст.txt` и `Общая_расшифровка_таймкоды.txt`.
* **Что делать, если при скачивании модели пропал интернет?**
  Просто запустите `Run Whisper.bat` ещё раз. Программа найдёт недокачанный файл `.part` в папке `models/large-v3-turbo/` и докачает оставшиеся мегабайты с места обрыва.
* **Что делать, если программа пишет, что не найдены CUDA-библиотеки?**
  Просто запустите ещё раз `Install Whisper.bat` — он докачает пакеты для видеокарты NVIDIA (`nvidia-cublas-cu12` и `nvidia-cudnn-cu12`). Даже если в вашем компьютере нет видеокарты NVIDIA, программа автоматически переключится на обычный процессор (CPU) и всё равно расшифрует запись.
