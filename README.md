# IvoryWhisperAIScript — Простая расшифровка видео и аудио в текст

Готовый набор программ для перевода любых видеозаписей, лекций, созвонов и голосовых сообщений в чистый текст на компьютере с Windows 10 или Windows 11. 

Вся обработка идёт прямо на вашей видеокарте (или процессоре) — бесплатно, без ограничений по длительности и без отправки личных записей на сторонние серверы.

---

## Что умеет эта программа

* **Переводит видео и аудио в текст:** поддерживает форматы `.mp4`, `.mkv`, `.avi`, `.mov`, `.mp3`, `.wav`, `.m4a`, `.webm`, `.flac`, `.ogg`.
* **Обрабатывает сразу много файлов:** можно выбрать как один ролик, так и целый курс лекций — программа по очереди расшифрует всё и соберёт в единый документ.
* **Создаёт сразу два удобных файла рядом с вашим видео:**
  1. `ИмяФайла_text.txt` (или `Общая_расшифровка_текст.txt`) — сплошной чистый текст, готовый для чтения, конспектов или отправки в нейросеть.
  2. `ИмяФайла_timestamps.txt` (или `Общая_расшифровка_таймкоды.txt`) — текст, разбитый по времени (`[00:01:15 -> 00:01:22] ...`), чтобы легко найти нужный момент в видео.
* **Работает даже на видеокартах с 4 ГБ памяти** (например, NVIDIA GeForce GTX 1650 Ti): если памяти видеокарты вдруг не хватит на тяжёлом файле, программа не вылетит и не испортит уже записанный текст, а сама переключится на более лёгкий режим.
* **Не боится российских блокировок:** скачивание языковой модели автоматически идёт через скоростное зеркало, а при желании модель можно положить в папку `models` и работать вообще без интернета.

## Быстрый старт (в 2 шага)

### Шаг 1. Установка (делается один раз)
Запустите двойным кликом файл **`Install Whisper.bat`**.

* Если у вас ещё не установлен Python, программа сама подскажет, что делать, и откроет страницу загрузки.
* Если Python уже есть (поддерживаются как стабильный **Python 3.14**, так и новый **Python 3.15**), установщик сам скачает все нужные библиотеки и создаст рабочий файл `translate_v4_argon.py`.
* Дождитесь надписи `[✓] Скрипт translate_v4_argon.py успешно создан!` и нажмите любую клавишу.

### Шаг 2. Расшифровка видео или аудио
У вас есть два удобных способа запуска:

1. **Через окно выбора файлов:**
   Запустите двойным кликом **`Run Whisper.bat`**. Появится стандартное окно Windows — выберите в нём один или несколько видео/аудиофайлов (несколько файлов можно выделить с зажатой клавишей `Ctrl` или `Shift`) и нажмите «Открыть».
2. **Перетаскиванием (Drag-and-Drop):**
   Просто перетащите мышкой нужный видеофайл (или сразу несколько файлов) прямо на иконку **`Run Whisper.bat`**. Расшифровка начнётся мгновенно без лишних окон.

> **Примечание при первом запуске:** когда вы запускаете расшифровку в самый первый раз, программа один раз скачает языковую модель (~1.6 ГБ). В следующие разы запуск будет происходить за пару секунд.

## Какой именно `.bat` файл запускать?

В папке лежат основные и дополнительные ярлыки запуска:

| Файл | Когда использовать |
| :--- | :--- |
| **`Install Whisper.bat`** | **Основной установщик.** Запускайте его в 99% случаев — он сам найдёт установленный у вас Python и всё настроит. |
| **`Run Whisper.bat`** | **Основной запуск расшифровки.** Запускайте его для ежедневной работы. |
| `Install Whisper (Python 3.14).bat` / `Run Whisper (Python 3.14).bat` | Если на вашем компьютере установлено сразу несколько версий Python и вы хотите принудительно использовать проверенную версию **Python 3.14** (с умным фильтром тишины). |
| `Install Whisper (Python 3.15).bat` / `Run Whisper (Python 3.15).bat` | Если вы хотите принудительно установить и запустить скрипт именно на свежем **Python 3.15**. |

## Как работать полностью без интернета (оффлайн-режим)

По умолчанию программа сама скачивает модель при первом запуске и сохраняет её в системный кэш. Если вы хотите перенести программу на компьютер без интернета:

1. Создайте рядом с батниками папку `models`, а внутри неё — подпапку `large-v3-turbo` (чтобы получился путь `models/large-v3-turbo/`).
2. Положите внутрь файлы модели (`model.bin`, `config.json`, `tokenizer.json`, `vocabulary.json` / `preprocessor_config.json`) из репозитория [deepdml/faster-whisper-large-v3-turbo-ct2](https://huggingface.co/deepdml/faster-whisper-large-v3-turbo-ct2) или [mobiuslabsgmbh/faster-whisper-large-v3-turbo](https://huggingface.co/rtlingo/mobiuslabsgmbh-faster-whisper-large-v3-turbo).
3. Теперь программа будет брать модель напрямую из папки `models/large-v3-turbo` без обращения к сети.

## Частые вопросы

* **Где искать готовый текст после завершения?**
  Прямо в той же папке, где лежит ваше исходное видео. Если вы выбрали один файл `Лекция_1.mp4`, рядом появятся `Лекция_1_text.txt` и `Лекция_1_timestamps.txt`. Если выбрали сразу несколько файлов — в их папке появятся `Общая_расшифровка_текст.txt` и `Общая_расшифровка_таймкоды.txt`.
* **Что делать, если программа пишет, что не найдены CUDA-библиотеки?**
  Просто запустите ещё раз `Install Whisper.bat` — он докачает пакеты для видеокарты NVIDIA. Даже если в вашем компьютере нет видеокарты NVIDIA, программа автоматически переключится на обычный процессор (CPU) и всё равно расшифрует запись.
